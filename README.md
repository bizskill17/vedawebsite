# VEDA Wellness & Spa

Static website source exported from the VEDA Sites project.

Serve the files in `dist/`. For Hostinger, upload the contents of `dist/` into the main domain's `public_html` folder, preserving any separate subdomain folders.

No build step or database is required. This repository does not automatically deploy to Sites or Hostinger.

The hero photograph is illustrative. Its reuse licence is unconfirmed; replace it with an authorised VEDA photograph before public launch. Source: https://www.wunderarchitectes.fr/leceltiquehoteletspa (photography credited to Germain Herriau).
